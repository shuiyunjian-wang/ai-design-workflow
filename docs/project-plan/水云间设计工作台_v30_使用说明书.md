# 水云间设计工作台 v30 · 功能说明与使用手册

> 版本定位：当前桌面 `水云间设计工作台.exe`（= v30）。累计 v1→v30。
> 一句话：把水云间设计咨询的「策略风水 → 彩平 → 3D → 渲染 → 精修 → 集成 → 发布」全链路，在统一窗口里由 AI 总办串联跑通，并让每次产出反哺知识库，越用越懂你家的风格。
> 本版相对 v29 的变化（**本地化优先，零网络**）：**② 知识库检索本地化**——用纯本地离线 BM25 索引替代远程 MaxKB 的检索角色（见第十节），不依赖任何外部服务；自动过滤模型拒答等垃圾卡；知识库 tab 新增搜索框 + 重建索引按钮。① 知识库已对齐 `sheji` 仓库并 git 化（v29）；③ 专家包清理、④ PDF 导出、⑤ 模型融合、⑥ 顶栏描边（v29）保持不变。

## 三、各功能使用说明

### 1. 生成（直接出效果图）
**用途**：不走智能体，直接写提示词让本机 SD 出一张室内设计效果图。

步骤：
1. 写**正向提示词**（要什么风格/空间/材质），可点「提示词标签墙」快速拼词，用「复制正向」带走。
2. 写**反向提示词**（规避模糊、变形、水印等）。
3. 设**出图参数**：模式（文生图 / 图生图）、采样器、宽高、步数、CFG；图生图需选底图。
4. （可选）展开 `ControlNet` 手动控制结构（预处理器 + 模型 + 权重 + 输入图）。
5. 选 **🌟 风格强调** 下拉，可叠加已训练风格（见第七节）。
6. 点「**出图（调用本机 SD）**」，结果在右侧「结果」区。

前提：本机 A1111 SD 已启动并勾选 API（默认 `:7860`）。

---

### 2. 方案（智能体团队出整套方案）
**用途**：给一句话或一张户型图，总办调度 7 个智能体产出完整设计方案，可含 SD 效果图。这是工作台的核心。

步骤：
1. 填**客户需求简报**（也可只传图，由视觉模型理解）。
2. 上传**参考图**（定风格）、**户型图**（可选）。
3. 选**工作流**：自动判定（推荐）/ A 全链路 / B 仅风水 / C 仅渲染精修 / 单智能体直调。
4. 勾「**用本机 SD 生成/精修效果图**」→ 展开 `SD 五层增强`，按需勾：
   - **ControlNet** 结构控制（gouju→线稿 / zhuying→深度 / fucai→线框+分割）
   - **IP-Adapter** 风格参考（权重可调）
   - **ADetailer** 细节修复（仅效果图含人物时勾）
   - **Upscale** 高清放大 + Tile 细节增强（室内精修标准做法）
5. 点「**生成完整方案**」，下方实时显示各阶段进度与最终结构化方案。
6. 用 `复制方案` / `导出方案册` / `项目档案打包`（命名：`{项目N}_{角色}_{YYYYMMDD}.{md|png}`，附 `_原图/` 子目录）。
7. **改图（反馈环 v26）**：点「✏️ 应用修改」输入修订意见（如"客厅主墙换暖灰、去掉金属线条"），可自动定位阶段、勾选「同步重绘效果图」用 SD 重画，修订记录写回档案。

前提：Ollama 在线（文本 `qwen2.5:7b` + 视觉 `qwen2.5vl:7b`）；SD 增强需 SD 在线且装对应扩展。

### 3. 知识库（素材沉淀 + 自动训练）
**用途**：把历史效果图、参考图、PDF 沉淀进各智能体知识库，空闲时自动训练，越用越懂你家风格。

子功能：
- **🔍 本地知识库检索（v30 新增，离线零网络）**：tab 顶部搜索框输入查询词（如「北欧 客厅 木质 灯光」「风水 玄关 鞋柜」「彩平 户型 动线」），点「搜索」即在全部 DNA 卡、案例库、风水/提示词与专家方法论中做本地 BM25 检索，返回标题/来源/评分/片段；可按智能体筛选；点「♻ 重建索引」可重新扫描全部 markdown 灌入最新知识。等价于「本地版 MaxKB 检索」——**不依赖任何外部服务、不上传任何数据**，模型拒答等垃圾卡在建索引时自动过滤。
  - 索引落盘于本机运行时目录 `~/.shuiyunjian_workbench/kb-index.json`（派生缓存，随知识库内容变化而重建，不进 git）。
  - 第一次打开或库有变动后，索引会在后台静默构建；也可随时点「重建索引」。
- **上传素材自动提炼 DNA 卡片**：拖图/PDF 进来，自动分类写进 `knowledge-base/case-studies/`（SD 图读参数、照片视觉模型看、PDF 提文本）。知识库根目录已对齐 `shuiyunjian-wang/sheji` 仓库（`case-studies` / `fengshui` / `prompts` 等），随 git 版本管理。
- **扫描本地文件夹**：选整个目录递归入库（适合一次性沉淀历史图库）。
- **填路径直接扫描（后端模式）**：填目录路径由后端遍历，不占前端内存，适合超大图库；可指定目标智能体或自动分类。
- **Eagle 素材库接入**：「测试连接」→「立即同步到知识库」→「重置已学习记录」（需 Eagle 桌面端开本地 API `:41595`）。
- **自动学习（空闲训练）**：启用后，电脑空闲超阈值或排程时段自动训练；可开「入库去重」「经验总纲自提炼」；设空闲阈值、每轮上限、排程起止；支持「立即学习一轮 / 立即提炼经验总纲 / 停止」，带实时日志。
- **各智能体独立知识库**：查看每个 agent 的卡片数与训练进度。
- **本地知识积累（cases/）**：按智能体筛选浏览已入库案例。

说明：每次跑方案，相应智能体会先检索自己知识库注入提示词——**知识越厚，水平越高**，这就是「自动训练」。

### 4. 团队
**用途**：查看工作台实际加载的 7 个智能体成员与职责（来源 WorkBuddy 专家包，原样复用）。

成员：观局（策略/风水）、勾勒（彩平/户型）、筑影（3D/透视）、赋彩（渲染/材质）、凝光（摄影精修）、集韵（集成/物料）、文心（发布文案）；总办（水云间）负责接单与编排。

### 5. 工作流
**用途**：展示标准 SOP 顺序——观局 → 勾勒 → 筑影 → 赋彩 → 凝光 → 集韵 → 文心，所有跨成员产出经总办中转。对照自查每个环节由谁负责。

### 6. PNG 方案信息（v28 新增）
**用途**：读 SD 出的 PNG 内嵌参数，复盘"这张图当时是怎么出的"，便于调提示词、批量复现好图。

三种用法：
1. 把本地 PNG **拖进框里**；
2. 点框**选文件**；
3. 点「**本机出图**」列表里最近生成的缩略图（去「生成」页出过图才会出现）。

展示内容：完整正向提示词、负向提示词、Steps、Sampler、CFG、Seed、Size、Model 等。

说明：纯本地解析，零依赖，不上传任何数据；非 SD 原生保存的图（如 PS 重存）或没参数的图会温和提示。

### 7. 风格库 / 风格训练
**用途**：把一套参考图提炼成「风格 DNA 卡」，出图时在「🌟 风格强调」下拉里选中，让 AI 自动贴你家调性。

训练步骤：
1. 点左侧「＋ 训练新风格」，或生成页「风格训练」卡片。
2. 填**风格名称**（如 `水云间新中式`）。
3. 选 **1~N 张参考图**（决定调性）。
4. 点「⚡ 提炼风格 DNA」→ 视觉模型读图生成风格卡（配色 / 材质 / 构图 / 禁忌等）。
5. 之后「生成」页「🌟 风格强调」下拉即可选该风格叠加到本次出图。

管理：左侧「风格库」列表可查看、选中、删除（删除走 `/api/style/delete`）。

### 8. 模型融合（v29 新增，已接入 A1111）
**用途**：把本机 Stable Diffusion 的多个 checkpoint 按权重融合成一个新模型，落盘到 SD 的 `models/Stable-diffusion/`，做「水云间专属底模」资产化。

步骤：
1. 左侧点「**模型融合**」→ 进入融合面板（左侧「快速设置」里现在显示「可用」）。
2. 点「**🔄 刷新模型列表**」：后端调用 `/api/sd/models` 读取本机 SD 已安装的 checkpoint（主/次/第三模型三个下拉）。
   - 若提示「本机 SD 未运行」，请先启动 A1111 绘世启动器并勾选 API（默认 `:7860`），再刷新。
3. 选 **主模型 / 次模型**（必填）；选 **第三模型**（仅 `triple sum` 模式生效，可留空）。
4. 选 **融合模式**：
   - `weighted sum` 加权求和（最常用，α/β 控制主/次权重）
   - `add difference` 加差异
   - `triple sum` 三模型求和（需第三模型）
5. 拖 **α / β** 滑块设混合比例（0~1，默认各 0.5）。
6. 填 **输出模型名**（不含扩展名，默认 `MergedModel`）。
7. 点「**⚡ 开始融合**」：后端调用 A1111 `/sdapi/v1/merge` 执行；融合是大模型运算，可能持续数分钟，按钮禁用并显示进度，完成后提示落盘路径。
8. 回到 SD 模型下拉刷新即可选用新融合模型。

说明：融合走本机 SD，必须 SD 在线；纯 WebUI 操作，不上传任何数据。

### 8.5 方案册 / 项目档案导出 PDF（v29 新增）
**用途**：把文字方案直接变成可发送客户的 PDF，不必再手动排版。

- **方案册 PDF**：方案页「📄 PDF」按钮（在「导出方案册」旁）→ 把当前方案 Markdown 渲染为 PDF 下载，渲染图以 base64 内嵌。
- **项目档案 PDF**：项目档案打包后，结果区「导出 PDF」按钮 → 把整个项目文件夹的所有 `.md`（含原图说明）合并导出为一个 PDF。
- 依赖：`reportlab`（已装）。若某图无法读取会温和跳过，不中断导出。

### 9. 知识库对接 MaxKB（网络推送，可选 / 暂缓）
**用途**：把本地 `sheji` 仓库的知识库同步进 MaxKB 做 RAG 问答（对外服务场景）。

> **v30 决策：本地化优先**。检索环节已用「本地知识库检索」（第十节）在离线完成，不依赖 MaxKB。MaxKB 网络推送仅作为「对外发布知识库」的可选项，默认不做（不联网、不对外输出）。

连接器：`sheji` 仓库 `tools/maxkb_sync.py`（纯标准库，零依赖）。
- 默认 **预览**：`python tools/maxkb_sync.py` 列出将上传的全部文档（当前约 3600+ 个 .md）。
- **实际上传**（需你提供实例后执行）：
  ```bash
  MAXKB_BASE_URL=http://你的MaxKB:8080 \
  MAXKB_API_KEY=user-xxxx \
  MAXKB_DATASET_ID=数据集ID \
  python tools/maxkb_sync.py --push
  ```
- 接口路径因 MaxKB 版本而异；默认走 `/api/dataset/{id}/document/_bach`。若你的版本是 workspace 路径，用 `MAXKB_UPLOAD_URL` 覆盖完整接口即可（详见脚本头部注释）。
- 状态：连接器已就绪并通过 dry-run 验证；**实际推送需要你提供 MaxKB 实例地址 + API Key + 数据集 ID**（社区版仅开放应用级 API，数据集级写入通常用专业版 API Key）。

### 10. 本地知识库检索（v30 新增，离线零网络）
**用途**：在完全不联网的前提下，对整套知识库做语义化检索——这就是 MaxKB「检索」环节在本地端的等价实现。引擎 `design-workbench/kb_index.py`（纯标准库、中文二元组 BM25、零 embedding 模型）。

工作原理：
- 扫描 `knowledge-base` 下全部 markdown（`case-studies` / 各智能体分库 `agents/*/cases` / `fengshui` / `prompts`），并可选纳入专家包系统提示词（真实方法论知识）。
- 建倒排索引 + BM25 打分，落盘 `kb-index.json`（约 30 MB，8420 篇有效文档 / 过滤掉 2332 张模型拒答垃圾卡）。
- 检索时按相关度返回标题、来源路径、所属智能体、评分、正文片段。

接口：
- `GET /api/kb/search?q=<词>&k=<条数>&agent=<可选>` → 命中列表
- `GET /api/kb/stats` → 索引状态
- `POST /api/kb/rebuild` → 重新构建索引（灌入最新知识）

优点：不依赖 Ollama embedding 模型、不联网、不污染远程；垃圾卡在建索引时即剔除，检索质量可控。

## 五、常见排错

- **出图无反应 / 报错**：先点「检测」看 SD 灯；确认 SD 已勾 API 且在跑。
- **方案生成卡住**：看 `planStatus`；确认 Ollama 在线（文本 + 视觉模型都在）。
- **SD 五层增强不生效**：点「检测 SD 扩展能力」，未装扩展的层会自动跳过，不影响其他层。
- **知识库不增长**：确认素材是图/PDF，或点「立即学习一轮」手动触发。
- **PNG 信息读不出**：只有 SD 原生保存的 PNG 才带参数块；后期用 PS 重存会丢失元数据。
- **模型融合报错 / 列表为空**：先点「刷新模型列表」；若提示 SD 未运行，确认 A1111 已启动并勾 API（默认 `:7860`）。融合是大数据运算，按钮转圈数分钟属正常。
- **PDF 导出失败**：确认运行环境已装 `reportlab`（桌面 exe 已内置）；某张图损坏会被跳过而非中断。
