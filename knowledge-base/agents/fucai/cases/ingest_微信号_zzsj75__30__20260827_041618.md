# 设计知识 DNA: 现代简约风格案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净利落，线条简洁，注重功能性和实用性。
- **光影逻辑**: 强调自然光的引入，减少复杂照明设计，通过大面积窗体和简洁灯具增加空间层次感。
- **主导材质细节**: 
  - 材质1: 天然木质，主要用作地板和局部墙面装饰，带来温暖的纹理感。
  - 材质2: 水泥质感墙面和地面，以粗糙材质呈现现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 这个色温范围可以更好地表现木质的自然光泽和水泥结构的清晰质感。 |
| **曝光补偿** | -1 - 0 | 轻微降低曝光度，以减少水泥墙面的反光，保持木质与水泥间温润的对比。 |
| **材质渲染词** | "木质地板"，"水泥质感"，"简洁灯具" | 确保材质和灯具的协调性，强调空间的纯粹与现代感。 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格强调简洁和实用性，通过木质和水泥材质的巧妙运用，打造干净利落且富有层次的空间感。
