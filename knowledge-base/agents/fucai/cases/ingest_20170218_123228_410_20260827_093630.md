# 设计知识 DNA: 现代简约设计案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 现代干净、简洁利落。
- **光影逻辑**: 强调自然光的引入，通过大面积落地窗和简洁的光影设计增加空间通透感。
- **主导材质细节**: 
  - 材质1: 不锈钢板，用于家具和装饰，展现光泽感和现代感。
  - 材质2: 高透光度玻璃，用作隔断和墙面，增加空间的明亮度。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 类似中午日光的色温，使空间显得明亮和清晰。 |
| **曝光补偿** | 0 | 稍微增加曝光补偿以突出现代材质的光泽感。 |
| **材质渲染词** | 金属光泽、透明质感 | 强调不锈钢的反光性和玻璃的透明感。 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格通过不锈钢和玻璃材质的应用，以及自然光的充分利用，创造出简洁明亮的空间氛围。
