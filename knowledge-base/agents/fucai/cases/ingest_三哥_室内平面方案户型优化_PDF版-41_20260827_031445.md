# 设计知识 DNA: 现代简约风格 - 居住空间

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 整体简洁而不失温馨，注重功能性和舒适性。
- **光影逻辑**: 强调自然光的引入，通过大面积落地窗和简洁的窗帘设计，使室内空间明亮开阔。
- **主导材质细节**: 
  - 材质1: 以温润的胡桃木为主，应用于地板和部分家具表面。
  - 材质2: 现代感较强的大理石，用作局部台面和墙面装饰。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K | 选择接近自然光的中性色温，营造温馨舒适的氛围 |
| **曝光补偿** | 0 | 保持自然光照度，避免过度曝光或欠曝 |
| **材质渲染词** | 温润胡桃木、纯净大理石 | 确保胡桃木温馨、自然光泽，大理石现代而明亮 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格强调简洁与舒适，通过胡桃木和大理石等材质的运用，提升居住空间的品质感。
