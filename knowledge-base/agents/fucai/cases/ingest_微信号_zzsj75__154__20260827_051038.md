# 设计知识 DNA: 极简现代

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 空气流畅，空间感强，线条简洁，视觉上注重留白。
- **光影逻辑**: 强调自然光的利用，配合大面积的窗户使室内光线柔和且明亮，夜间则通过隐藏式灯光勾勒空间轮廓。
- **主导材质细节**: 
  - 材质1: 深色实木，为墙面或大型家具带来丰富质感和温度。
  - 材质2: 浅色石材，作为台面或装饰墙，形成对比并增加空间轻盈感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K - 4000K | 给出中性至暖色调，强调自然光感 |
| **曝光补偿** | -1到-2 | 适度减少曝光，使得整体画面更加明亮 |
| **材质渲染词** | "木质纹理", "石材光泽" | 准确描述材质的真实触感和外观 |

## 3. 知识卡片摘要 (For Quick Indexing)
极简现代风格注重简洁线条与自然材质的结合，以流畅的空间感和细腻的光影处理为特色。
