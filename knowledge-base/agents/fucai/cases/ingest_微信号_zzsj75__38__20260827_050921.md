# 设计知识 DNA: 极简北欧风

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 清新简洁，强调自然与功能并重。
- **光影逻辑**: 以柔和自然光为基调，避免强烈对比，强调光影对空间氛围的塑造。
- **主导材质细节**: 
  - 材质1: 采用大量自然木材，如橡木、松木，通过简洁加工手法保留自然纹理。
  - 材质2: 充分运用温和色调的皮革，增加质感与舒适感。
