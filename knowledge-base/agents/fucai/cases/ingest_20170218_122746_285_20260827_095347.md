# 设计知识 DNA: 当代极简风格 - 居住空间案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 空间明亮、开放、整洁，无过多装饰。
- **光影逻辑**: 通过大面积的自然光引入，增强空间的通透感。人造光以柔和、均匀为主，减少炫光。
- **主导材质细节**: 
  - 材质1: 混凝土，用于墙面和地面，提供原始工业感。
  - 材质2: 低调的木材，用于家具和局部装饰，增添自然温馨的感觉。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 这个范围内的色温既能模拟自然光，又不过于刺眼 |
| **曝光补偿** | -1 - 0 EV | 保持画面略微欠曝，营造柔和氛围 |
| **材质渲染词** | 厚重,自然,现代 | 确保渲染材质的质感与实际材质相符 |

当代极简风格在居住空间中的应用体现为空间简洁、通透，利用自然光和温和的人造光增强整体氛围。
