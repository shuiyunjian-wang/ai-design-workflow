# 设计知识 DNA: 现代简约

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 明亮、简洁、通透
- **光影逻辑**: 强调自然光的引入与利用，大面积使用半透明材质增加空间的层次感
- **主导材质细节**: 
  - 材质1: 自然木质，给人亲切自然之感
  - 材质2: 半透明玻璃，增加室内流动性和通透性

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 适宜人眼，符合自然光效果 |
| **曝光补偿** | 0 | 保证清晰细节，不过曝或欠曝 |
| **材质渲染词** | "透明玻璃细节，自然木质纹理" | 指导AI精确捕捉材质特性 |

## 3. 知识卡片摘要 (For Quick Indexing)
