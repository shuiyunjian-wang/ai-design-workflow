# 设计知识 DNA: 极简现代风格

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净利落，注重线条感。
- **光影逻辑**: 采用自然光为主，通过大面积落地窗引入自然光，并利用灯光进行层次划分。
- **主导材质细节**:
  - 材质1: 木质，选用自然色调，展现温暖而柔和的触感。
  - 材质2: 钢材质，强调其简洁直线和冷硬感，增强现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K - 4500K | 温暖至中性色调 |
| **曝光补偿** | -0.3 - 0 | 控制适当的阴影与高光细节 |
| **材质渲染词** | 温润木质，冷硬钢铁 | 突出材质对比，提升视觉冲击力 |

## 3. 知识卡片摘要 (For Quick Indexing)
极简现代风格通过简约的线条和自然的光影对比实现空间的舒适与美观。
