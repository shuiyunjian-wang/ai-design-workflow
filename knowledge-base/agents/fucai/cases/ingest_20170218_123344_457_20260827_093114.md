# 设计知识 DNA: 极简现代

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简洁利落，摒弃繁杂装饰，呈现自然舒适的居住环境。
- **光影逻辑**: 强调自然采光和简单照明设计，利用大面积的玻璃窗和柔和的灯光营造通透舒适的室内氛围。
- **主导材质细节**: 
  - 材质1: 采用自然木质，注重保留木材的纹理和自然美感。
  - 材质2: 配以现代金属，如不锈钢或是亮面铝材，体现工业风格的简洁现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K左右 | 保持自然白光，以还原材料的真实色彩 |
| **曝光补偿** | -1 - 0 | 稍微降低曝光，保持环境温暖而不失透亮 |
| **材质渲染词** | 温暖木质，现代金属 | 确保渲染中木材清晰自然，金属简洁清晰 |

## 3. 知识卡片摘要 (For Quick Indexing)
精准运用材质对比，通过简洁线条和自然元素营造现代极简风格的生活空间。
