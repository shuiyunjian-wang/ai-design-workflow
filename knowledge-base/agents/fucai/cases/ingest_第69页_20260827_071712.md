# 设计知识 DNA: 现代简约风格案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 清新、明亮、舒适
- **光影逻辑**: 大面积使用简洁的矩形窗体，营造柔和的室内光线。通过自然光线的引入和人造照明的补充，保持空间明亮且通透。
- **主导材质细节**: 
  - 材质1: 白色墙面，搭配浅灰色地面，营造干净、简洁的空间感
  - 材质2: 天然木质元素，如木质地板、家具，增添自然气息
  - 材质3: 金属元素，如金属框架的灯具、家具，增加现代感

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K - 4000K | 温暖而不失自然 |
| **曝光补偿** | -0.3 或 0 | 保持场景明亮度 |
| **材质渲染词** | “木质的温暖质感”、“金属的冰冷质感” | 表现材质之间的对比 |

## 3. 知识卡片摘要 (For Quick Indexing)
通过简洁材质的对比与光线的配合，打造出清新且现代的居家空间。
