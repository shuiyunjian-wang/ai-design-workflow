# 设计知识 DNA: 现代极简风格设计案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净、明亮、简约，富有现代感。
- **光影逻辑**: 利用大面积的玻璃和天窗引入自然光，营造明亮愉悦的氛围。
- **主导材质细节**:
  - 材质1: 木质地板和木饰面，自然温馨。
  - 材质2: 玻璃墙和钢化玻璃门，呈现通透、轻盈的感觉。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K-6500K | 呈现自然光效果，保持空间明亮和冷暖平衡 |
| **曝光补偿** | -1 - 0 | 适度减小曝光，还原木质和玻璃材质质感 |
| **材质渲染词** | "自然木质纹理", "钢化玻璃窗框", "亮泽地面" | 强调材质的细节和质感 |
