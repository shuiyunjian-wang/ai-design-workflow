# 设计知识 DNA: 现代简约风格家居案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简洁、明亮、功能性强
- **光影逻辑**: 自然光与人工光源互补，避免直射，强调柔和的光影效果
- **主导材质细节**: 
  - 材质1: 自然木质，强调质感与温暖
  - 材质2: 棉麻纺织品，营造舒适、自然的触感与视觉氛围

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3000-4000K | 温暖而不刺眼的中性色调 |
| **曝光补偿** | +0.3EV | 稍微增加曝光，增强细节 |
| **材质渲染词** | 木质、棉麻、软布 | 确保材质细节在视觉上突出 |

## 3. 知识卡片摘要 (For Quick Indexing)
注重材质质感与光影效果，打造简洁明快的生活空间。
