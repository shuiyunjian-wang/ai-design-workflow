# 设计知识 DNA: 极简风格住宅空间

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 清新、宁静，强调空间流畅性和功能性。
- **光影逻辑**: 自然光利用最大化，简洁的光影线条，突出空间的层次感。
- **主导材质细节**: 
  - 材质1: 淡雅的木质，以天然的纹理和温润的触感营造舒适氛围。
  - 材质2: 钢化玻璃和金属，透明材质与木质的碰撞，增添现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 清冷的中性色调，适合极简风格 |
| **曝光补偿** | -1 | 略微降低曝光度，强调材质的自然质感 |
| **材质渲染词** | 木质纹理、钢化玻璃光泽 | 渲染时突出材质的自然质感和光泽度 |

## 3. 知识卡片摘要 (For Quick Indexing)
通过简洁的线条和自然材质，营造出一种清新、宁静的生活氛围。
