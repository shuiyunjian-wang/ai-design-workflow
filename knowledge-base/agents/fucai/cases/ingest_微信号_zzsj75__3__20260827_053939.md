# 设计知识 DNA: 现代极简风格案例

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 轻盈、通透、简洁。
- **光影逻辑**: 强调自然光与简洁照明的结合，利用大面积玻璃窗让光线自由流动，同时通过暗哑处理的材质反射光线，增加空间通透感。
- **主导材质细节**:
  - 材质1: 深色木材，如橡木，纹理细腻，为室内增添温暖触感，用作地板、墙面和家具。
  - 材质2: 透明或低反射率玻璃，用于室内隔断和窗户，保证室内空间的开阔感和清晰视线。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K-5500K | 这一色温范围能够提供自然且舒适的照明效果 |
| **曝光补偿** | -1/-2 | 避免过度曝光，适合现代极简风格的室内 |
| **材质渲染词** | 木材：哑光/深色；玻璃：半透明/低反射 | 材质质感的精确描述 |

## 3. 知识卡片摘要 (For Quick Indexing)
一句话总结该案例的独特设计手法：利用深色木材与透明玻璃的对比，营造现代极简风格的居住空间。
