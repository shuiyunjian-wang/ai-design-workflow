# 设计知识 DNA: 不支持的文件类型

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 文件类型相关的未授权素材无法直接提供视觉内容，故无法描述具体的空间气质。
- **光影逻辑**: 同上，无法明确描述光影逻辑。
- **主导材质细节**: 由于缺乏具体视觉材料，主导材质无法明确，但通常文件类型相关的空间会呈现纸质质感、光洁的屏幕表面等。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K-6500K | 均衡的自然光到温暖的室内照明，具体数值根据实际情况选择。 |
| **曝光补偿** | 0-+1 | 适量调整，根据具体情况微调曝光补偿。 |
| **材质渲染词** | 纸张纹理，光洁屏幕 | 与文件类型相关的材质进行结合渲染。 |

## 3. 知识卡片摘要 (For Quick Indexing)
由于素材不支持直接引用，此案例主要关注文件类型相关的空间和材质细节。
