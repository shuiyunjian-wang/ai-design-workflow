# 设计知识 DNA: 现代简约风格案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简净、明亮、开放、整洁。
- **光影逻辑**: 强调自然光的引入，使用大面积的玻璃窗，光线柔和洒满空间。
- **主导材质细节**: 
  - 材质1: 清润木质，常用于家具和地板，展现自然的纹理。
  - 材质2: 光滑的玻璃，用于隔断和门，增强空间的通透感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 偏冷色调，模拟自然光效果 |
| **曝光补偿** | -0.3 | 略减曝光，增强材质质感 |
| **材质渲染词** | 清润木质、光滑玻璃 | 突出材质质感和通透感 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格通过木质与玻璃的完美融合，营造明亮、通透且充满自然光照的空间氛围。
