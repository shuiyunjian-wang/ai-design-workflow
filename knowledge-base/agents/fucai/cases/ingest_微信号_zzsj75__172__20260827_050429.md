# 设计知识 DNA: 现代极简风格案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 清新、通透、自然、简洁
- **光影逻辑**: 强调自然光，通过大窗户引入外部景色，利用局部灯光增强立体感
- **主导材质细节**: 
  - 材质1: 木纹面板，自然且温暖的木色为主
  - 材质2: 镀铬钢材，光泽且带现代感的金属质感

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3700K - 4200K | 温暖的白光，营造舒适氛围 |
| **曝光补偿** | -1 - 0 | 适当降低曝光，增强材料质感 |
| **材质渲染词** | 暖色木纹、冷调镀铬 | 渲染时注重材质质感对比 |

## 3. 知识卡片摘要 (For Quick Indexing)
简约而不简单，现代极简风格通过简洁的线条和自然的材质打造出清新自然的居住空间。
