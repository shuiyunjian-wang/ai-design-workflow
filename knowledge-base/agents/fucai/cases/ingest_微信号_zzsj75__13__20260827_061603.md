# 设计知识 DNA: 现代简约风格

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净、简洁、明亮、舒适
- **光影逻辑**: 自然光与人工光相结合，营造温馨舒适的氛围，重点突出空间层次
- **主导材质细节**: 
  - 木材: 淡色橡木，营造自然和谐的感觉
  - 金属: 银色或不锈钢，用于装饰边框和细节点缀

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 营造舒适而现代的空间氛围 |
| **曝光补偿** | -1 - 0 | 保持照片清晰，但不损失细节 |
| **材质渲染词** | 木质感强，金属冷暖对比 | 高光与暗调结合，增加层次感 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格通过木质与金属的对比，以及适度的光影处理，营造了一个舒适且具有设计感的生活空间。
