# 设计知识 DNA: 现代简约风格

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净利落、明亮通透
- **光影逻辑**: 强调自然光，利用大面积落地窗引入自然光照，减少灯饰
- **主导材质细节**: 
  - 材质1: 木质（原木、竹材），自然温馨
  - 材质2: 金属材质（铝、不锈钢），精致现代

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K左右 | 适合现代简约风格的自然光感 |
| **曝光补偿** | 0 | 良好的光照情况下无需额外调整 |
| **材质渲染词** | "清水木纹", "金属光泽" | 体现质感 |

## 3. 知识卡片摘要 (For Quick Indexing)
通过简洁的线条和高质感的材质，营造出现代简约的空间氛围。
