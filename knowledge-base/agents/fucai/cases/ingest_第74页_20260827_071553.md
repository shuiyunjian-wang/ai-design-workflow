# 设计知识 DNA: 现代简约办公室设计

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 极简、开放、明亮
- **光影逻辑**: 自然光与人工灯光结合，增强空间通透感
- **主导材质细节**: 
  - 材质1: 深色木质框架与白色木质面板
  - 材质2: 透明玻璃隔断

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K-4500K | 适合办公室用光，营造专业而舒适的氛围 |
| **曝光补偿** | -1到-2 | 适当减少曝光，使照片更加清爽而不失细节 |
| **材质渲染词** | 木质、玻璃、白色 | 突出主要材质及对比 |

## 3. 知识卡片摘要 (For Quick Indexing)
简约而不简单的设计理念，运用自然材质创造宁静专业的工作环境。
