# 设计知识 DNA: 无图片素材

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 现代且简约，强调线条感和功能实用性。
- **光影逻辑**: 大量使用自然光源，结合镜面材质增强室内光影层次感。
- **主导材质细节**: 
  - 材质1: 金属，如不锈钢和铝合金，展现光滑简洁的质感。
  - 材质2: 玻璃，如钢化玻璃隔断，增加透明通透的效果。

| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |

| **曝光补偿** | 0 | 正常曝光，不过度强调光影或反差 |
| **材质渲染词** | 金属光泽，镜面效果 | 强调光泽和反光效果 |
