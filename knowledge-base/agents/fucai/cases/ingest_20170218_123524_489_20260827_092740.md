# 设计知识 DNA: 现代简约风格家居案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 清新、简洁、明亮、开放、实用。
- **光影逻辑**: 利用大面积的自然光，强调透明感和通透空间感。通过不同光源的层次布局，创造丰富光影效果，但避免过于复杂的光影层次。
- **主导材质细节**: 
  - 材质1: 光泽度适中的白色或浅灰色乳胶漆墙面，营造明亮宽敞的视觉效果。
  - 材质2: 天然木质地板，表面处理细腻，保留木材自然纹理；结合现代金属条，体现精致细节。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K 或 5000K | 中性偏冷色调，增强明快感，营造清新气质。 |
| **曝光补偿** | -1 或 0 | 保持空间自然通透，曝光度微调。 |
| **材质渲染词** | "木质肌理"，"玻璃透明"，"乳胶漆平滑" | 渲染时突出材质的真实性和质感。 |

## 3. 知识卡片摘要 (For Quick Indexing)
精准运用简洁材质与自然光，营造现代简约风格室内空间感。
