# 设计知识 DNA: 现代简约

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 通透，简洁，注重功能性和空间的流畅过渡。
- **光影逻辑**: 强调自然光线，利用大窗户引入自然光，白天较少使用电光源。
- **主导材质细节**:
  - 材质1: 天然实木，质感细腻，常用于墙面和家具。
  - 材质2: 镀铬金属，常用于框架和装饰线条，体现现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 自然的白平衡 |
| **曝光补偿** | 0 | 保持自然光线 |
| **材质渲染词** | 木质自然，金属光泽 | 突出自然材质与金属线条 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格强调功能性和自然材料的使用，通过简洁的线条和自然光影营造舒适的空间感。
