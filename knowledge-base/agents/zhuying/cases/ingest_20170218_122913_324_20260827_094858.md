# 设计知识 DNA: 现代简约住宅设计案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 空间明亮、整洁，强调线条简洁流畅，色彩以白色和灰色为主，配以少量鲜艳色彩点缀生活气息。
- **光影逻辑**: 利用大面积自然采光和简单线条的投影，创造出轻盈明亮的空间感。使用窗帘、百叶窗等可调控光线进入的设备。
- **主导材质细节**: 
  - 材质1: 深色实木地板，增强空间的稳重感。
  - 材质2: 金属装饰线条，增加空间的现代感和结构感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K-5000K | 适合明亮的现代空间 |
| **曝光补偿** | +1-+2 | 保证充足的亮度，但不过曝 |
| **材质渲染词** | 木质纹理细致，金属线条简洁明快 | 渲染时强调材质的真实性和工艺感 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格住宅设计注重简洁明亮的效果，通过线条和色彩的控制营造出轻松舒适的居住环境。
