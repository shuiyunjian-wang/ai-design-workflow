# 设计知识 DNA: 现代简约风格住宅设计

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 通透、简洁、舒适。
- **光影逻辑**: 采用大面积自然光，通过半透明窗帘调节光线强度，形成柔和而明亮的室内环境。
- **主导材质细节**:
  - 材质1: 实木，主要使用橡木，纹理清晰，温润自然。
  - 材质2: 不锈钢，线条流畅，光泽感强，用于细节点缀与强化设计感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度         | AI 提示词建议值              | 注释                                       |
| :----------- | :-------------------------- | :---------------------------------------- |
| **色温 (Kelvin)** | 4500K - 5500K            | 自然舒适色光，避免过于冷或者暖的极端色调   |
| **曝光补偿** | -1/3 EV - 0 EV           | 保持适当的曝光，避免过曝或欠曝             |
| **材质渲染词** | 实木质感、不锈钢光泽、纹理清晰 | 渲染时注重材质的真实性和细节的真实性       |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格住宅设计通过简洁的线条和自然的材质，营造出温馨而舒适的居住环境。
