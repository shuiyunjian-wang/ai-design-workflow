# 设计知识 DNA: 现代简约办公空间

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简洁明了、流畅大方
- **光影逻辑**: 通透明亮、弱对比，利用自然光
- **主导材质细节**:
  - 材质1: 自然木材质感，如橡木或胡桃木，温暖而质朴
  - 材质2: 影响光感的混凝土或白色水泥，表面纹理均匀、质感坚固

## 2. 量化提示词参数 (Prompt Parameters)
| 维度         | AI 提示词建议值         | 注释 |
| ------------ | ---------------------- | ---------------------- |
| **色温 (Kelvin)** | 5000K-5500K | 温和自然的白光，减少眼睛疲劳 |
| **曝光补偿** | -0.5 - 0.5 | 确保明亮区域不会过曝，阴影区域不会过暗 |
| **材质渲染词** | 暖色调木材，冷色调混凝土 | 着重渲染质感和材质特有的光线反映 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约办公空间通过利用自然光线和温暖的木质元素与冷却的混凝土材质，打造出一种既简洁又舒适的办公氛围。
