# 设计知识 DNA: 现代简约风格-住宅设计案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净、简洁，注重功能与美观的结合。
- **光影逻辑**: 强调自然光的引入和内部灯光的柔和补充，形成层次丰富的光影效果。
- **主导材质细节**: 
  - 材质1: 深色实木，用于构建家具和地板，展现自然质感与温馨氛围。
  - 材质2: 透明或浅色玻璃，用于分隔空间和引入自然光，增强室内外的通透感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3000K - 5000K | 中性色温，用于平衡自然光和人工光的效果。 |
| **曝光补偿** | -1 - 0 | 控制室内外光线差异，使整体效果自然。 |
| **材质渲染词** | 木纹、玻璃、半透明 | 提高3D模型材质的真实感。 |
