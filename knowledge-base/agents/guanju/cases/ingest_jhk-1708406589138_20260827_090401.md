# 设计知识 DNA: 现代简约风格住宅案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简洁明快，注重功能性与实用性。
- **光影逻辑**: 自然光线充分引入室内，通过大面积玻璃窗或天窗。
- **主导材质细节**: 
  - 材质1: 实木质感的木质地板和家具，营造自然温馨感。
  - 材质2: 微水泥或岩板的墙面，提供光滑简约的表面。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 中性偏冷，保证明亮的室内氛围。 |
| **曝光补偿** | 0 | 正常曝光，不过曝也不欠曝，适合拍摄整体场景。 |
| **材质渲染词** | 木质感、光泽度、光滑表面 | 重点渲染木材的自然纹理和微水泥的细腻质感。 |
