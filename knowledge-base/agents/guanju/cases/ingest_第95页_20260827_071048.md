# 设计知识 DNA: 现代简约风格案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简约而不简单，追求功能与美学的和谐统一。
- **光影逻辑**: 强调自然光线的引入，使用简洁的线条打破沉闷，形成光与影的自然对话。
- **主导材质细节**: 
  - 材质1: 自然木材质感，提供温馨舒适的生活气息。
  - 材质2: 金属材料的应用，增添现代感和工业感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K – 5500K | 偏冷的中性色调，营造清晰、利落的空间氛围 |
| **曝光补偿** | -1 - 0 | 略微减少曝光，保持光线自然不过曝 |
| **材质渲染词** | 清晰的木纹，冷调金属质感 | 确保材质细节清晰，同时保持金属的冷峻与光泽 |
