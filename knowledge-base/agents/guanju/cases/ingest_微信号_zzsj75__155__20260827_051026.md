# 设计知识 DNA: 几何极简

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 空间内大量运用直线和几何形状，营造理性和现代感。
- **光影逻辑**: 光线采用直射与漫反射相结合的方式，强化简洁的空间体验。
- **主导材质细节**:
  - 材质1: 金属（镜面和抛光不锈钢），强调现代感和秩序感。
  - 材质2: 原始玻璃，增加视觉轻盈感并引入自然光线。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 合适的自然光和人造光照平衡值，适用于现代办公环境。 |
| **曝光补偿** | 0 | 直接光照和漫反射光的自然平衡，不需要额外调整。 |
| **材质渲染词** | 金属、不锈钢、镜面、玻璃、自然光 | 渲染时需强调金属的光泽对比和玻璃的轻盈透明感。 |
