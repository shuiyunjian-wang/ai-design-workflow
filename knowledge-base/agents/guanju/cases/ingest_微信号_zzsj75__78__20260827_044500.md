# 设计知识 DNA: 现代极简风格住宅

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净、流畅、极简
- **光影逻辑**: 强调空间的自然光，弱化人工照明，充分利用透光性和反射性材质
- **主导材质细节**:
  - 材质1: 透明玻璃，用于增强空间通透感和光线流动性
  - 材质2: 清洁的木质表面，用以营造温暖舒适的空间氛围

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K | 自然光的色温，确保空间明亮而不失温馨 |
| **曝光补偿** | 0 | 无需过度补偿，维持自然光线的自然展现 |
| **材质渲染词** | 透明、光滑、自然、温暖 | 强调材质在不同光线下的效果 |

现代极简风格住宅通过透明玻璃和清洁木质材料营造出开阔、明亮且舒适的居住环境。
