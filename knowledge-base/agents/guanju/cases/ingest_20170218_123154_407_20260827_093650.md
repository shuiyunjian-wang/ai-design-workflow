# 设计知识 DNA: 极简现代风格 - 居住空间实例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 干净、简洁、明亮
- **光影逻辑**: 通过大面积玻璃窗引入自然光线，营造通透感
- **主导材质细节**: 
  - 材质1: 玻璃，强调光线与空间的流动
  - 材质2: 木质，温暖且自然

## 2. 量化提示词参数 (Prompt Parameters)
| 维度       | AI 提示词建议值             | 注释                                     |
| :--------- | :------------------------- | :--------------------------------------- |
| **色温 (Kelvin)** | 5000K                      | 自然光色调，保持室内光线清爽不刺眼         |
| **曝光补偿** | -1/3 至 0 EV                | 确保图像明亮不过曝，不过暗                 |
| **材质渲染词** | "通透玻璃"、"自然木质"、"简洁线条" | 渲染材质时强调材质的本质美感                 |

## 3. 知识卡片摘要 (For Quick Indexing)
简洁线条与自然材质的结合，营造现代居住空间的纯净与温暖。
