# 设计知识 DNA: 不支持的文件类型

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 无特定风格，融合多种元素，展现出多元文化的碰撞与和谐。
- **光影逻辑**: 利用自然光和人工光创造丰富的层次感与光影效果，营造氛围。
- **主导材质细节**: 
  - 材质1: 金属质感
  - 材质2: 木纹装饰

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K, 5000K | 营造温暖与现代感 |
| **曝光补偿** | -1, 0 | 增强对比度与层次感 |
| **材质渲染词** | 金属质感, 木纹质感 | 突出材质的细节 |

## 3. 知识卡片摘要 (For Quick Indexing)
多元文化的融合与光影材料的运用，创造出独特且富有层次感的空间。
