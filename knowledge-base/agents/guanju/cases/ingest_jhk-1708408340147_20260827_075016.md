# 设计知识 DNA: 现代简约

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 开放、明亮、通透，注重简洁实用。
- **光影逻辑**: 通过大面积自然光的应用，强调光影的层次感和透明感。使用大型落地窗引入外部自然光线，内部尽量减少遮挡。
- **主导材质细节**: 
  - 材质1: 清晰的木质纹理，自然且有温暖感，主要应用于地板、家具和装饰。
  - 材质2: 透明或半透明的玻璃，用于隔断和墙板，带来通透感和视觉延伸。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4500K-5000K | 适用于自然光和部分人造光源的色温范围。 |
| **曝光补偿** | +1EV | 保证充足的曝光，避免过度曝光或曝光不足。 |
| **材质渲染词** | 温暖木纹，现代透明玻璃 | 增强空间的自然与现代感。 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格通过大量使用木质与玻璃材质，营造明亮通透的空间感和简洁明快的视觉效果。
