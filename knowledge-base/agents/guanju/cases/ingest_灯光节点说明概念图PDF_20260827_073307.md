# 设计知识 DNA: 现代极简风格

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简洁明快，功能性强，色彩淡雅。
- **光影逻辑**: 强调自然光的引入，利用简洁的灯饰增强空间的层次感，避免复杂的光影效果。
- **主导材质细节**:
  - 材质1: 木质——温馨自然，通过细腻的木纹强化空间温暖感。
  - 材质2: 金属——质感强烈，通过金属线条的运用增加空间的现代感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K | 这个色温下光源更接近自然光，营造明亮舒适的室内环境。 |
| **曝光补偿** | 0 | 无需额外调整，自然光和简单灯具即可满足室内照明需求。 |
| **材质渲染词** | 温暖木质、冷调金属 | 突出材质的对比效果，使空间更具层次感。 |

## 3. 知识卡片摘要 (For Quick Indexing)
简洁的线条、明亮的空间和自然的材料营造出现代极简风格的独特氛围。
