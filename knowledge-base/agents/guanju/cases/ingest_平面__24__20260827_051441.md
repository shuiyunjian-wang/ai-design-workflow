# 设计知识 DNA: 现代简约风格住宅

## 1. 核心视觉特征 (Visual DNA Description)
- **空间气质**: 通透明亮，简洁舒适
- **光影逻辑**: 大面积使用自然光，通过天窗和大窗户引入自然光线，增强室内光感。
- **主导材质细节**: 
  - 材质1: 原木，自然质感，给人温暖舒适的感觉。
  - 材质2: 深灰色石材，用于台面和背景墙，简洁而富有质感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 温和自然的白光，适合展示材质细节 |
| **曝光补偿** | -1 - 0 | 略微不足的曝光增强氛围 |
| **材质渲染词** | 温暖木材、深灰石材 | 突出主要材质质感 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格住宅通过简洁的线条和自然的材质营造舒适温馨的生活空间。
