# 设计知识 DNA: 新中式风格设计案例

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 清雅、自然、传统韵味浓厚，以传统文化元素和现代审美相结合。
- **光影逻辑**: 注重自然光的引入和利用，通过拉帘、落地窗等设计增加空间通透感和层次感。
- **主导材质细节**: 
  - 材质1: 淡色调的木板和精致的雕花，营造温馨和谐的氛围。
  - 材质2: 大理石地面或墙面，彰显稳重与雅致，同时增加空间档次感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500K (略显暖调) | 适应环境的温馨感 |
| **曝光补偿** | -1 EV | 为了显示木质细节纹理 |
| **材质渲染词** | 木质感强，质感清晰 | 强调木质纹理和质感 |

## 3. 知识卡片摘要 (For Quick Indexing)
传承传统元素的同时兼具现代审美，新中式风格呈现出独特的文化韵味和艺术气息。
