# 设计知识 DNA: 平面布置优化

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 高效实用，简洁明快。
- **光影逻辑**: 自然光线充足，辅以间接照明增加层次感。
- **主导材质细节**: 
  - 木材质感自然温馨，利用木纹细节表现。
  - 布艺软装软化空间硬朗线条。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K | 使空间看起来更加自然和舒适 |
| **曝光补偿** | 0 | 保持图像的自然亮度，不加不减 |
| **材质渲染词** | 木材、布艺、自然光 | 以这些核心材质和光影为渲染重点 |
