# 设计知识 DNA: 平面布置优化

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 简约明快，注重功能性与空间利用。
- **光影逻辑**: 尽量利用自然光，通过不同高度的设计布局引入或限制光线。
- **主导材质细节**: 
  - 材质1: 木质元素，自然、温暖，为家居空间增添温馨氛围。
  - 材质2: 现代金属，结合实木家具，强化现代感与轻盈感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 3500-4000K | 提供接近自然光的视觉效果 |
| **曝光补偿** | 0-+0.5 EV | 适应不同光线场景的灵活曝光 |
| **材质渲染词** | 木质家具，现代金属框架 | 渲染时突出材质搭配的现代感 |
