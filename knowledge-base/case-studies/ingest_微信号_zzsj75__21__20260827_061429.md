# 设计知识 DNA: 现代简约风格居住空间

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 清新、明亮、极简
- **光影逻辑**: 通透采光，利用大面积窗户引入自然光
- **主导材质细节**:
  - 材质1: 原木，自然纹理清晰，使用在地板和部分墙面
  - 材质2: 玻璃，透明或半透明，主要用作隔断和窗户

## 2. 量化提示词参数 (Prompt Parameters)
| 维度     | AI 提示词建议值          | 注释                                   |
| -------- | ----------------------- | -------------------------------------- |
| **色温 (Kelvin)** | 5000K-6000K          | 适合现代简约风格的中性光氛，突出简洁材质 |
| **曝光补偿** | -1 -0                  | 控制明亮的自然光照度，让空间显得不过于刺眼 |
| **材质渲染词** | "简洁线条、自然质感" | 强调设计中线条的利落和材质的自然感       |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格居住空间通过自然材质和通透的光影营造清新明亮的氛围。
