# 设计知识 DNA: 现代北欧风格住宅空间

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 温馨、简约而不失质感。
- **光影逻辑**: 大面积落地窗引入自然光，辅以柔光灯和镜面反射增加室内亮度。
- **主导材质细节**: 
  - 材质1: 木材（主要为橡木和松木，表面采用自然漆处理，体现自然美感）
  - 材质2: 棉麻（墙面和窗帘等装饰采用棉麻材质，增加居家舒适感）

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 4500K | 北欧风格偏好较冷色调，有利于营造清新、明亮的空间氛围 |
| **曝光补偿** | -1 - 0 | 冷色调的空间中，适当的曝光补偿可以使颜色更加真实且不白化 |
| **材质渲染词** | 木质纹路、棉麻质感、自然漆 | 增强材质的真实感和使用感 |

## 3. 知识卡片摘要 (For Quick Indexing)
独特设计手法在于通过自然光与柔光结合，以及木材、棉麻等天然材质的应用，展现温馨与简约并存的居住环境。
