# 设计知识 DNA: 现代极简

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 极简主义氛围，注重功能性和实用性，营造开放且通透的空间感。
- **光影逻辑**: 强调自然光的引入和使用，通过大面积的玻璃窗和轻薄的隔断来创造明亮、清爽的空间感。光影变化为简约的空间注入活力。
- **主导材质细节**: 
  - 材质1: 地板采用浅色实木，纹理清晰自然，提升空间的温暖感和层次感。
  - 材质2: 墙面使用大面积的简洁涂料，墙面颜色为白色或浅灰色，增加空间的通透感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K-6500K | 适合自然光和柔和的室内光源，为白色调空间提供最佳视觉效果。 |
| **曝光补偿** | -1 或 0 | 控制适当的暗度，增加空间的深度感，避免过度曝光。 |
| **材质渲染词** | 地板：实木清漆；墙面：光滑涂料 | 渲染材质的选择和处理方式，以提升视觉效果。 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代极简风格通过明亮的自然光和自然的木材纹理，创造出一个简洁而温馨的生活空间。
