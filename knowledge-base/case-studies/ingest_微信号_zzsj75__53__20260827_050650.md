# 设计知识 DNA: 极简工业风办公室

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 精简、原始、开放
- **光影逻辑**: 大面积采光，自然光线透过大面积玻璃窗洒入室内，营造自然明亮的空间氛围。人工照明主要通过裸露的灯管和简约灯具实现，光线柔和而不刺眼。
- **主导材质细节**:
  - 材质1: 水泥地面，粗糙质感，保留原始状态
  - 材质2: 金属框架与管材，多见于隔断和悬挂结构，形成工业风的标志性元素
  
## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 4000K - 5000K | 工业风偏爱冷色调，适合4000K - 5000K的色温 |
| **曝光补偿** | -1 - 0 | 照片需要稍微减少曝光，保留空间的明亮感 |
| **材质渲染词** | 水泥地面、裸露金属框架、玻璃窗、管材结构 | 

## 3. 知识卡片摘要 (For Quick Indexing)
通过精准的材质运用与光影处理，创造一种原始而现代的办公空间体验。
