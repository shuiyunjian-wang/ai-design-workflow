# 设计知识 DNA: 现代简约风格居住空间

## 1. 核心视觉特征 (Visual DNA Description)
> 此部分用精确文本替代图片，用于指导 AI 生成提示词。
- **空间气质**: 空旷明亮，线条简洁，功能性强，颜色以黑、白、灰调为主。
- **光影逻辑**: 强调自然光的引入和使用，通过大面积窗户和镜面反射增强室内空间深度和开放感。
- **主导材质细节**: 
  - 材质1: 采用天然木质地板和家具，木质色调温暖而不失现代感。
  - 材质2: 金属框架和线条，如金属门框、灯具，强调轻巧、现代的质感。

## 2. 量化提示词参数 (Prompt Parameters)
| 维度 | AI 提示词建议值 | 注释 |
| :--- | :--- | :--- |
| **色温 (Kelvin)** | 5000K左右 | 保持冷白色调，增强现代感 |
| **曝光补偿** | +1 或 0 | 确保图像清晰明亮，不偏暗 |
| **材质渲染词** | 木质表面、金属线条、玻璃透亮 | 重点强调材质质感 |

## 3. 知识卡片摘要 (For Quick Indexing)
现代简约风格通过简洁的线条和自然材质，营造明亮舒适的居住环境。
