## 三、关键决策与攻坚

### 1. PDF 工具链缺口 → fpdf2 + 系统字体
本沙箱**无任何** HTML→PDF 现成工具（wkhtmltopdf / pandoc / chromium / weasyprint / playwright / reportlab 均无）。改用**纯 Python `fpdf2 2.8.8`**（零系统依赖），中文用系统 `simhei.ttf` / `simkai.ttf`。

### 2. fpdf2 三处坑（已逐一修复）
- **`multi_cell(0,…)` 宽度塌陷**：封面 `cell` 把内部 x 推偏，导致可用宽度 0 报错。→ 所有段改为显式 `W = pdf.w - l_margin - r_margin` 且每段前 `set_x(l_margin)`。
- **`FontFace` 非法参数**：`font_size=` 不被接受。→ 改为 `FontFace(color=…, fill_color=ACCENT, size_pt=9)`。
- **simhei 缺失字形**：`◉/⚠/•` 显示空白。→ 加 `_clean()` 统一替换（◉→○、⚠→[注意]、•→·），应用于所有写文本入口。

### 3. jiyun 品牌化整合（签核制）
主理人建团队 `shuiyunjian-proposal` → 调度 jiyun 认领 Phase 4 → jiyun 回传签核文案，逐字注入 `DEFAULT_INTEGRATION`：
- 封面副标：`以 AI 之眼，承古法之韵，安一处天地人和的居所`
- 设计理念、施工注意事项（5 条，含碧桂园级收口/横梁/命卦呼应/留白聚气/五行色彩纪律）、物料清单（6 条五行泄法 + 色彩/植物纪律）全部替换为专业文案
- 新增封底页：`集大成，韵天成 —— 让方案本身就是一件作品。`
- **边界**：风水推导核心（八方星位 / 门主灶三要判语 / 综合解读 / 命宅合参 / 命卦导入法诚实声明）**全程保持原样未改**，仅品牌化增补。

### 4. GitHub 资产归档
- 工作区非 git 仓库；现网克隆实为 `ai-design-workflow`（origin = `github.com/shuiyunjian-wang/ai-design-workflow.git`，即 SOP 所称 `shuiyunjian-wang/sheji` 现网仓库，命名差异以现网为准）。
- 原 `.gitignore` 全局忽略 `*.pdf` → 新增 `!outputs/`、`!outputs/**/*.pdf`、`!outputs/**/*.html` 解除忽略。
- 归档路径：`outputs/2026-08-11-张先生新居-风水方案册/`，本地提交 `4b8ef63`（PDF+HTML+gitignore）。

### 5. 网络硬阻断（环境限制，非操作错误）
远端推送三次交叉验证失败：`github.com` / `gitee.com` / `1.1.1.1` 的 443 全部超时（HTTP 000），无代理变量、无 git 代理。→ 本沙箱**无任何出站路由**，远端同步在环境层面不可能。
